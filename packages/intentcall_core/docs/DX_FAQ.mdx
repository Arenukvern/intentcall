## 🏠 Smallest host

**Q: What is the smallest non-Flutter integration?**

```dart
import 'package:intentcall_core/intentcall_core.dart';

final registry = InMemoryAgentRegistry();
registry.register(myEntry.toRegistration());
final result = await registry.invoke('namespace.name', arguments);
```

Custom adapters publish metadata, translate calls, and route back through `registry.invoke`.

---

## 🔌 Adapter discovery

**Q: How does an adapter read the catalog?**

```dart
final registry = InMemoryAgentRegistry();
final entries = registry.listEntries();
```

Subscribe to `registry.events` when the transport supports hot-sync. Publish and invoke by `AgentRegistryEntry.key`, not descriptor display strings.
