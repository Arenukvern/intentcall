# intentcall_webmcp — DX FAQ

---

## 🌐 Publish adapter

**Q: How do I attach WebMCP to a registry?**

Use `WebMcpPublishAdapter` (same attach/publish/invoke rhythm as MCP). Enable registration only on pages that expose a compatible WebMCP host (`registerWebMcp: true` in `IntentCallFlutterHost` on web).

Contract tests: `packages/intentcall_webmcp/test/webmcp_adapter_contract_test.dart`.

---

## 📤 Projection

**Q: How does manifest export include WebMCP?**

Set `AgentManifestSurface.webMcp` in `@AgentProjection` / `EntryProjection` or rely on web platform defaults during `intentcall manifest export`. Generated JS may land in `web/intentcall_webmcp.generated.js` via codegen examples.
