## 🔌 Minimal adapter

**Q: What is the adapter checklist?**

1. Attach to an `AgentRegistry`.
2. Publish each `registry.listEntries()` row by stored key.
3. Subscribe to `registry.events` when the transport supports hot-sync.
4. On invoke, call `registry.invoke(entry.key, arguments)`.
5. Detach cleanly; add `verifyNativeAdapterContract(...)` in tests.

Reference test: `packages/intentcall_mcp/test/mcp_adapter_contract_test.dart`.

## 🧪 Contract test

**Q: How do I test my adapter?**

Use the same shape as `mcp_adapter_contract_test.dart`: pass `adapter`, `isPublished`, `invoke`, and `normalize` to `verifyNativeAdapterContract`. Construct `McpPublishAdapter` with `publishTool` and `unpublishTool`, then `await adapter.attach(registry)` before the contract runs.

Run `steward benchmark --scenario intentcall.adapter-contract --json` before claiming compliance.
