## ✅ Validation

**Q: How do I validate arguments before invoke?**

```dart
final errors = validateAgainstSchema(arguments, inputSchema);
if (errors.isNotEmpty) {
  return AgentResult.failure(message: errors.join('; '));
}
final coerced = coerceArgumentsForSchema(arguments, inputSchema);
```
