## ✅ Validation

**Q: How do I validate arguments before invoke?**

```dart
import 'package:intentcall_schema/intentcall_schema.dart';

final coerced = coerceArgumentsForSchema(inputSchema, arguments);
try {
  validateAgainstSchema(inputSchema, coerced);
} on AgentValidationException catch (error) {
  return AgentResult.failure(message: error.message);
}
```
